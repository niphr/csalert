# Print a csfmt_ensemble_v4

Prints one line: the state, the number of rows and of series, and the
names of the draw matrices.

## Usage

``` r
# S3 method for class 'csfmt_ensemble_v4'
print(x, ...)
```

## Arguments

- x:

  The `csfmt_ensemble_v4` to print.

- ...:

  Not used. The [`print()`](https://rdrr.io/r/base/print.html) generic
  has it.

## Value

`x`, invisibly.
